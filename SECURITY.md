# 安全问题 / Security issues

## 简体中文

如果发现可能影响用户隐私或浏览器安全的问题，请使用 GitHub 仓库的 **Security → Report a vulnerability** 私密报告入口。如果该入口不可用，请发邮件至 [mergedao@gmail.com](mailto:mergedao@gmail.com)。请勿先在公开 Issue 中披露漏洞细节。

报告中请写明受影响的版本、复现步骤、预期与实际结果，以及可能的数据影响。维护者会确认报告、评估修复，并在适当时发布新版本。安全修复时间取决于问题严重程度与 Chrome 应用商店审核。

## English

If you find an issue that may affect user privacy or browser security, use the repository's private **Security → Report a vulnerability** flow. If that option is unavailable, email [mergedao@gmail.com](mailto:mergedao@gmail.com). Please do not disclose vulnerability details in a public issue first.

Include the affected version, reproduction steps, expected and actual behavior, and potential data impact. The maintainer will acknowledge and assess the report, then release a fix when appropriate. Timing depends on severity and Chrome Web Store review.
