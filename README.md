# 码一下 QR

Chrome 扩展：在网页图片上右键识别二维码、截取当前可见页面并框选识别，以及为网址、链接或选中文字生成二维码。所有生成和识别都在本地完成，不需要账号或服务器。

## 功能

- 图片右键 → **码一下 QR → 识别这张图片的二维码**。扩展截取当前可见页面，优先扫描右键图片在截图中的区域。若图片被遮挡、部分超出画面，或位于 iframe 中，可在结果页手动框选。
- 页面右键或工具栏 → **截图当前画面并框选识别**。在结果页拖动鼠标框选二维码。
- 工具栏输入网址或文字生成二维码；在页面、链接和选中文字上右键可直接生成。
- 可上传本地图片识别；可复制识别结果、复制二维码图片或下载 PNG。

## 本地开发

需要 Node.js 20.19+。运行 `npm install` 和 `npm run build`，然后在 `chrome://extensions` 打开开发者模式，选择“加载已解压的扩展程序”，选中 `dist` 文件夹。运行 `npm run package` 可生成商店上传所需的 ZIP。

## 权限

`activeTab` 仅在用户点击扩展或右键菜单时访问当前标签页；`contextMenus` 添加右键入口；`scripting` 用于定位右键图片在当前页面的位置；`storage` 临时传递截图和内容到结果页。扩展不申请全站访问权限，不发送图片、网址或二维码内容到服务器。详见 [隐私政策](PRIVACY.md)。

## 已知边界

截图只覆盖当前可见画面，不会自动滚动整页。右键图片若在屏幕外、被覆盖或在跨域 iframe 内，自动定位可能失败，可以手动框选或上传图片。二维码识别针对标准 QR Code，不包括条形码、Data Matrix 等其他码制。
